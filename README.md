# VESTA – AI Wardrobe Guide

## Proje Hakkında

VESTA, kişisel stilini keşfetmek ve gardırobunu daha verimli kullanmak isteyen kişiler için tasarlanmış yapay zekâ destekli bir web sitesi konseptidir.

Proje; akıllı gardırop yönetimi, AI kombin asistanı, renk ve stil uyumu, akıllı bavul ve sürdürülebilir moda konularını tanıtır.

## Hedef Kitle

Kişisel stilini geliştirmek, kıyafetlerini daha bilinçli kullanmak ve teknoloji destekli moda çözümlerini keşfetmek isteyen kullanıcılar.

## Sayfalar

- **Ana Sayfa (index.html):** VESTA'nın tanıtımı ve temel özellikleri.
- **Keşfet (icerikler.html):** Beş farklı stil ve gardırop konusunu içeren kartlar ve arama sistemi.
- **Hakkında (hakkinda.html):** Projenin amacı, hikâyesi ve temel değerleri.

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Özellikler

- Üç sayfada ortak navigasyon menüsü.
- Beş farklı içerik kartı.
- Başlıklara göre anlık arama.
- Türkçe karakter uyumlu arama.
- Dinamik sonuç sayacı.
- Sonuç bulunamadığında bilgilendirme mesajı.
- Aramayı temizleme özelliği.
- Responsive tasarım hedefi.

## Projeyi Çalıştırma

1. Proje dosyalarını bilgisayarınıza indirin.
2. Proje klasörünü Visual Studio Code ile açın.
3. `index.html` dosyasını tarayıcıda açın.
4. Daha rahat geliştirme ve test için VS Code Live Server eklentisini kullanabilirsiniz.
5. Keşfet sayfasından arama özelliğini deneyebilirsiniz.
